## Політика HTTP-відмов

Для чужих ресурсів обрано політику 403 Forbidden.

- 401 Unauthorized — користувач не виконав вхід у систему.
- 403 Forbidden — користувач автентифікований, але не має права виконати дію над ресурсом.
- 404 Not Found — ресурс із зазначеним ідентифікатором не існує.

Політику 403 обрано для того, щоб явно повідомляти автентифікованому користувачу про відсутність необхідних прав доступу.

Обрана політика застосовується послідовно до перегляду деталей, оновлення, видалення інцидентів та доступу до дочірніх коментарів.

### Аудит привілейованої дії

У разі відмови в POST /api/incidents/{id}/triage сервер записує подію authorization.denied.

Подія містить: ідентифікатор користувача з перевіреного principal, назву дії, ідентифікатор інциденту, результат denied, час UTC та traceId запиту.

Паролі, cookie, токени та повне тіло HTTP-запиту не записуються.
